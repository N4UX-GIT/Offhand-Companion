# Privacy statement

Offhand Companion does not collect telemetry, analytics, crash reports, gameplay,
chat, credentials, account information, advertising identifiers, or personal data.

This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.

The only network feature is **Check for Updates**. When the user clicks that button,
the Companion makes an HTTPS request to the official GitHub Releases API. GitHub may
process ordinary connection metadata under the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
The Companion does not send configuration, display, WoW, or SavedVariables data in
that request.

All Companion preferences remain on the local computer under
`%LOCALAPPDATA%\Offhand`. Files read from a World of Warcraft installation are used
locally and are not transmitted.
